# AI Disaster Commander v0.3.0 审核报告

日期：2026-10-22。环境：Windows x64 / Python 3.14 / 本机 Chrome。审核基线：85c85d3e958103789be129f09a3e51bc7464ef6f；交付提交号记录在包内 DELIVERY-MANIFEST.json。

## 结论

可作为街区或园区地震救援演练的小团队空间 RAG 原型交付。账号、审核、工作空间隔离、时空查询、路网、局部三维配准和确定性关系推理有可运行的自动验证；本次发现并修复 6 类应用缺陷，升级 2 个命中已知安全公告的依赖。

这不是公网生产就绪或现场救援安全认证。模型识别质量、真实测绘精度、现场道路安全、高并发容量及灾难恢复时限尚无验收数据。不能将测试通过解释为“无漏洞”或“结果绝对可靠”。

## 范围与方法

- 审阅 app/、frontend/ 自有业务代码、tests/、examples/、依赖锁及部署文档；跟踪身份、工作空间、审核与证据过滤的调用链。
- 运行基线测试；对账号撤销、容量、竞态、极端时间和非法模型配置做可复现探测，修复后补回归。
- 使用实际 FastAPI 临时后端与 Chrome 验证登录注册和完整业务链路。浏览器集成中的模型及搜索为测试桩，未调用收费供应商。
- pip-audit 2.10.1 检查锁定的 28 个 Python 运行依赖；OSV 检查两项直接纳入前端的 npm 库。比对 9 个 vendor 文件哈希；MapLibre 官方 npm 包提取前校验发布元数据的 SHA-512 integrity。
- 检查 Git 待交付源码中的常见密钥前缀及私钥头；不扫描真实 data 目录，也未做 Git 全历史秘密扫描。
- 独立安装锁定依赖、检查 SQLite 备份恢复及交付包文件完整性。没有侵入正在使用的现场数据库。

## 发现及修复

严重性为本项目审阅判断；上游公告分数不直接等同于本应用的可利用性。

| 问题 | 影响及复现 | 修复与证据 |
| --- | --- | --- |
| 高：命令行停用后重新启用会恢复旧凭据 | 旧登录会话在启用后再次返回 200；与永久撤销预期不符，重置码也可能恢复 | app/manage.py 停用时轮换凭据摘要并清除重置码；测试同时验证旧 session、个人令牌、重置码始终失效 |
| 中：账户容量耗尽导致审批 500 | 达到 AccountConfig 的 1000 用户上限后，追加用户触发模型验证异常 | 在写入前返回 409，保留待审批申请；容量边界测试通过 |
| 中：中断审批留下的申请无法清理 | 账号已创建但申请残留，approve/reject 都冲突 | 允许拒绝同名残留申请；禁止重复批准或覆盖已有账户；回归通过 |
| 中：注册使用过期账号快照 | 密码计算期间命令行可能创建同名账户或变更管理员状态 | 在共享账号锁中重新读取配置，再检查账号与启用管理员；测试模拟哈希期间并发创建同名账户，不产生脏申请 |
| 中：极端时区和日期触发溢出 | year 1 减时间窗或 UTC 转换越界，检索可抛未处理异常 | 在共享时间校验中同时校验 UTC 与本地偏移的范围，API 返回 422；query/reason 极端值与合法边界回归通过 |
| 中：非法模型 URL 未被统一处理 | 错误 IPv6、端口格式等可能在请求前抛 ValueError | 三条模型调用共用 HTTPS URL 校验，转为已有“服务未配置/不可用”路径；非法 URL 不会发出网络请求 |
| 高：certifi 信任库命中安全公告 | PYSEC-2026-4320 / GHSA-6q48-6c7w-9gw2；受影响 CA 链的中间证书私钥泄露，存在特定条件下 TLS 拦截风险 | 2026.7.22 → 2026.10.19；锁文件更新，复扫无命中 |
| 上游严重：MapLibre HTML 清理绕过 | GHSA-jrc7-96c5-q579 / CVE-2026-85061；不可信署名中的相邻危险属性可绕过清理。本项目署名硬编码，未证实页面存在该攻击入口 | 5.6.2 → 6.4.1，改为本地 ESM/shared/worker；真实浏览器验证事件属性与 javascript: 链接被清除、未执行，地图与 worker 正常 |

对应新增回归在 tests/test_accounts.py、tests/test_audit.py、tests/vendor_browser_check.py。没有更改用户已认可的地图主导布局、悬浮窗方式或登录主视觉。

## 尚存限制及上线前事项

1. **部署与容量**：本地磁盘 SQLite、小团队、单机。内部查询仍有全量扫描，未做大规模数据、高并发、长时间运行或断电故障注入。没有业务存储配额、自动清理和监控告警验收；公网必须配 HTTPS、受控代理、限流、备份和访问权限。
2. **账号事务**：JSON 账号与 SQLite 注册申请不具备跨文件原子提交；中断后可能留下申请，现可安全拒绝清理。文件原子替换不等于断电耐久保证；文件 ACL、备份保管由部署者负责。没有 SSO、MFA、邮件找回，登录凭据仅在页面内存中，刷新需登录。没有强制双人复核。
3. **图片与隐私**：仅 Base64、格式签名和 5 MB 上限检查，没有完整解码、像素上限或 EXIF 清理；上传者须控制图片内容与来源。第三方模型实际处理照片，部署者需核对其数据政策。Esri 接收瓦片区域请求，使用条款及生产用量需确认。
4. **证据的时间含义**：as_of 限制采集时间，使用当前审核状态，不是历史状态回放；冲突证据尚无事实裁决。道路有效期由审核路网快照控制，不能把可达结果等同于每条关联图片都满足同一 max_age_hours 窗口或现场实时安全。
5. **三维与推理**：配准是控制点相似变换、独立检查点及对象范围核验；没有照片自动重建、任意 mesh/点云导入或自动对应。复杂关系是受约束的显式图搜索和确定计算，不是通用因果推理；blocks 不传递。
6. **模型验证**：本轮只做协议/失败路径与模拟结果验证，没有重做真实供应商联调、费用测试或现场识别评估。README 中 2026-10-19 的联调记录是历史结果，不代表今日服务 SLA。AnySearch 仅未核实背景；星云 3D 为数字人 SDK，未用作配准服务。
7. **供应链与测试边界**：Python 锁文件固定版本但未含 wheel 哈希，干净安装仍信任安装源；扫描不能发现未知漏洞。没有做专业渗透测试、源码形式化证明、全浏览器矩阵或全部 Git 历史秘密扫描。Starlette TestClient 仍提示 httpx 弃用；当前测试通过，未来升级需迁移验证。
