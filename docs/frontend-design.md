# 指挥台设计对照

界面交互沿用用户提供的产品参考，视觉层采用用户提供的 ai_disaster_commander_kunsthalle_vellum_atlas_v0_3_0.html。保留本项目数据和后端接口，没有引入参考产品的商标、截图或商业代码。

视觉层级以地图为主：默认纸本测绘主题使用米白纸色、黑色框线、红蓝强调与硬边阴影；顶部可切换高对比的粗野档案和深色的矿物岩彩。顶部使用四个工作流入口，替代八项纵向菜单。对象、图层、时间、关系、照片及问答按需浮于同一张地图；相关操作在工作窗内用标签合并。审核画布、缩略图和属性编辑器保留清晰分区。

桌面窗口的整条标题栏可拖动，拖动柄提供方向键微调；活动窗口通过边框及前后层级表达焦点，拖动显示抓取光标。收起后进入底部托盘，恢复保留位置和查询/审核草稿，工作窗可放大。手机采用固定位置浮层。新打开的窗口置前，边界校正防止窗口移出可操作区。素材与三维工作窗隐藏背景信息窗，并将现场切换、刷新放进工作窗工具栏。三套主题同步地图及三维颜色，文字前景与按钮底色分别调整对比度；实际布局截图与功能、对比度检查分别验收。

登录页恢复原 HTML 的白色表单、黄色按钮与浅绿分屏设计，标题使用本项目名称。默认首页及 #login 均显示登录页，支持真实账号登录、注册申请、用户改密和管理员一次性重置码；个人令牌仍通过本机连接入口接入，令牌只保存在页面内存。注册只能申请加入已有工作空间并等待管理员批准，Google/Apple OAuth 尚未接入且不显示虚假按钮，离线演练另设入口。原有认证、审核租约和数据边界保持；登录样式与渲染独立放在 login.css / login.js，工作台主题由 atlas.css 管理。局部 40 米地图网格仅作显示辅助，不作为测绘精度或真实安全判断依据。

已查看可访问的官方公开页面及产品展示图。ArcGIS 示例在检查期间停留于加载界面，该项根据用户提供的定向影像交互要求实现，未声称核验其完整产品流程。公开宣传页不等于产品全部操作界面，本项目也不声称逐像素复刻。

技术选择：MapLibre GL 负责影像地图和 GeoJSON 图层；Three.js 负责街区局部三维；原生模块及表单承接现有 FastAPI。版本、许可证、图源、启动方法、已验证路径与未实现能力见 [前端说明](../frontend/README.md)。
