## 路网验证

- 从 XML 保留 27 个节点、25 段道路。坐标来自 OSM；每段长度按原始相邻节点球面距离计算。
- 仅处理这份存档的 residential、track；排除私有/限制通行 service 道路和只有一个节点的裁剪片段。track 保守设为步行；不支持的方向/限制标签报错。不是通用 OSM 导航导入器。
- 所有道路均为 unknown，不将历史地图当作现场通行调查。coordinate_basis=measured 在本次输入中表示真实来源，不表示逐点实测或测绘精度认证。
- 应用 Dijkstra 与独立 Floyd–Warshall 比较：步行 729 对、车辆 729 对，共 1,458 对节点查询一致，包括不连通情况。该对照验证算法一致性，不证明地图本身完整。
- 样本路径 osm-n274969431 → osm-n5937853362：212.7156549576 米；不是经实地验证的救援路线。
- 只有显式选择 mapped_topology 才允许经过 unknown，返回每条未核实路段；默认 reviewed_status 无可用通行路线。封闭、单向、通行方式、避让、审核与撤回门槛保持生效。

## 三维配准验证

使用上游参考变换定位候选对应关系，从 reading 扫描固定均匀采样 250 个点，在 reference 扫描中寻找最近真实点。筛选初始距离小于 0.2 米且目标不重复的 185 对，再均匀选取 80 对，交替分为 40 对拟合点、40 对不参与求解的检查点。源点和目标点均来自原始扫描，未用同一批点的数学变换冒充第二份观测。

| 指标 | 实测 |
| --- | --- |
| 拟合 RMSE | 0.076275 米 |
| 检查 RMSE | 0.094863 米（约 9.49 厘米） |
| 所有选中点最大残差 | 0.220188 米 |
| 相对上游参考旋转差 | 0.278604° |
| 相对上游参考平移差 | 0.028083 米 |
| 预先设置的门槛 | RMSE ≤ 0.15 米、单点 ≤ 0.30 米；参考旋转差 < 0.5°、平移差 < 0.08 米 |

**检查点虽然不参与拟合，但对应关系的选择依赖上游参考变换并经过阈值筛选。9.49 厘米是选定对应点的条件误差，不是独立测绘精度，也不是全扫描准确率。** 筛选前 250 个采样点的最近邻距离中位数、90% 分位数和最大值分别为 0.086618、0.661764、4.349240 米；未隐藏全样本存在的大误差或非重叠部分。

target_frame=local 保留 XYZ 与 matrix_scene_to_local，wgs84=null。API 拒绝给局部配准伪填地理原点，也拒绝用未标定轴向推断地理上下关系。界面展示 80 对配准点和残差，不展示完整扫描网格，不声称完成摄影测量重建。

## 审核、时效与自动化边界

完整 API 计算在可销毁临时数据库运行。自动化明确标记为合同检查，验证待审拒绝 409 → 临时测试批准 → 拓扑路径/坐标变换 → 撤回后拒绝 409；人为破坏一个检查点 1 米时返回 422。临时数据库随后删除，不冒充人工现场审核。

本机正式导入保持候选待审，没有批准记录；需审核员核对来源后自行决定。工件使用区间 2026-10-23T05:15:01.863576Z 至 2026-10-30T05:15:01.863576Z 是行政使用有效期，不是扫描采集时间或现场路况有效期；过期需重新核验、提交新快照。

本机导入记录在 data/real-geometry/live-import.json。曾在重试核对时因集合 JSON 顺序产生一份同内容待审路网副本；已修复为按校验模型比较并复用检查点 ID，没有删除或批准副本。审核时使用该文件所指 network ID，避免重复批准。

## 复现与查看

~~~powershell
.venv/Scripts/python.exe -m examples.validate_real_geometry
# 后端 :8000 已以 local 模式启动时，导入并保留待审：
.venv/Scripts/python.exe -m examples.import_real_geometry
# 前端 :8080 同时运行后，只读验证真实数据页面：
.venv/Scripts/python.exe tests/real_geometry_browser_check.py
~~~

验证不会调用付费模型。首次下载需要网络，后续可使用通过散列核对的缓存。重新执行计算会生成新的行政使用区间，导入工具仅复用相同快照，不自动批准或替换旧版本。

打开 http://127.0.0.1:8080/#command，通过“连接设置”连接 http://127.0.0.1:8000，再用现场选择器选择：

- Real OSM topology：地图有 27 个真实节点；在“道路可达性”查看原始路网 JSON 与审核状态。待审道路不会进入正式地图路网层或查询。批准后仍需明确选择“仅地图拓扑”才能跨越 unknown。
- Real 3D scans：进入“三维配准与误差核验”，查看 XYZ、40+40 对点、检查误差和待审状态。局部扫描没有地图落点。

自动检查：56 项后端测试通过；现有浏览器套件覆盖账户、32 个响应式页面、真实数据表单和证据边界；另有真实几何只读页面检查。截图在本机 data/real-geometry/workbench-roads.png、workbench-registration.png。

## 尚不能宣称的结果

没有同一灾害现场的“照片—实地路况—三维测绘控制点”联合验证，没有灾时可通行结论，也没有厘米级绝对地理精度认证。原海地照片缺失的精确位置和 GCP 仍然未知。完成这部分需要来源明确的同场地测绘控制点、独立检查点以及带采集时间的路况调查，不能通过另一城市地图或人为构造坐标补齐。
