# AI Disaster Commander · 空间指挥台

面向街区地震演练的地图工作台：影像地图作为持续存在的底层视口，对象、图层、时间、关系及证据问答以悬浮窗口联动。顶部合并为「地图工作台」「素材与审核」「空间分析」「三维核验」四组流程，保留八个可直接访问的路由。

视觉采用用户提供的 Kunsthalle Vellum Atlas HTML：默认「纸本测绘」，使用纸色底、黑色框线、红蓝强调和矩形悬浮窗；顶部可切换「粗野档案」「矿物岩彩」。主题同步作用于地图、时间图和三维视口，只保存在当前页面会话中，刷新恢复默认。切换主题保留查询和审核文字草稿及连接身份；文件上传控件重绘后需重新选文件。登录页保留原 HTML 的白色表单、黄色按钮与浅绿分屏设计，接入后端账号登录、注册申请、密码修改和管理员重置码；第三方 OAuth 暂未接入，因此不显示虚假入口。

使用原生 ES Modules 和 CSS，地图采用 MapLibre GL 6.4.1，局部三维采用 Three.js 0.180.0。固定版本脚本和许可证保存在 vendor/，来源及哈希见 vendor/sources.json；无需 Node 或构建步骤。MapLibre 的主模块、shared 模块和 worker 模块必须一起部署，静态服务器应将 .mjs 作为 JavaScript MIME 类型提供；Python 3.14 的 http.server 已验证。影像瓦片来自 Esri World Imagery，需要联网，地图保留来源署名。部署方应按其服务条款安排生产用量及授权；可在 gis.js 替换瓦片源。第三方只接收瓦片范围请求，图片和令牌不发往瓦片服务。

## 预览

在仓库根目录运行：

    .venv/Scripts/python.exe -m http.server 8080 --bind 127.0.0.1 --directory frontend

打开 http://127.0.0.1:8080/ 或 http://127.0.0.1:8080/#login 进入登录页。ES Modules 必须通过 HTTP(S) 加载。

登录后选择后端现场，或从「上传资料」建立真实现场。未连接时可以浏览空工作台，但不能查询、上传或审核；启动、退出及过期不会装入模拟资料。世界底图仅作位置参考。工作台仅接受标记为 measured 的现场与 field_image 图片；含演练图片或演练位姿的混合现场会拒绝载入，历史记录仍保留在后端。来源标记是录入声明，并非独立核验。

## 连接后端

在另一个 PowerShell 窗口启动当前版本后端：

    $env:DISASTER_CORS_ORIGINS = 'http://127.0.0.1:8080'
    .venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

在登录页填写管理员创建的账号与密码，展开「连接设置 · 工作空间」指定后端地址与工作空间，点击「登录工作台」。注册页提交加入已有工作空间的申请，管理员批准后才能登录；用户可在账号管理中修改密码，忘记密码时由管理员签发 30 分钟一次性重置码。会话有效期 8 小时，刷新需重新登录；退出会撤销该会话。保留「使用个人令牌 / 本机连接」折叠入口与工作台的「连接设置」，local 模式可留空令牌。顶部账号徽章可返回登录页。账号管理和服务器初始化参见 [多人部署](../docs/team-deployment.md)。已有进程需以对应 CORS 配置重启。schema 5 升级前应备份数据库。

- 密码、令牌只在页面内存中保存，刷新页面后需重连；远程团队地址仅接受 HTTPS。退出会清理当前现场、图片对象与草稿，收到 401 后返回登录页；403 不清除有权继续使用的会话。
- 读取 /auth/me 和工作空间现场目录；照片以认证 Blob 加载，列表逐页读取；工作台不装入演练资料。
- 显示真实角色；写入权限、空间隔离、并发冲突由后端校验。使用「刷新」读取他人更新。
- 审核可领取五分钟租约，另一个审核员持有租约时后端拒绝提交；无租约时仍按首次成功提交生效。无自动续期，关闭页面后租约到期释放。409 保留当前审核意见供复核。
- AI 分析使用 Idempotency-Key，不自动重试。模型和搜索可能产生费用；超时后先核对结果再发起新分析。

## 页面及交互

- 桌面及平板宽屏（大于 640px）：拖动窗口的**整条标题栏**移动，点击窗口将其置于前景；标题左侧拖动柄可用方向键微调。标题右侧按钮分别用于收起、关闭，工作窗另有放大/还原。
- 收起的窗口从底部托盘恢复；也可从地图工具栏或顶部分组重新打开。位置在当前页面会话内保留；不会保存到账号或其他设备。窗口被限制在工作区内，调整浏览器大小后重新校正。
- 640px 及以下采用固定位置的浮层，不支持拖动；内容在窗口内滚动。地图仍可平移、缩放。
- 「素材与审核」内含素材库、上传资料、现场观察和人工审核；「空间分析」内含道路可达和关系查证。窗口切换、收起时保留当前会话的查询及审核表单草稿；刷新页面清空。文件上传表单切换后需重新选文件。
- 素材与三维工作窗打开时，背景信息窗暂时隐藏；当前现场切换与「刷新」合并到工作窗标签栏旁，审核时可以读取队友更新。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 现场态势 | #command | 实体树、影像底图、关系图、图层开关、距离圈、双端时间窗、播放、定向照片、问答与引用 |
| 资料导入 | #import | 地图 JSON、PNG/JPEG、可选相机位姿 |
| 图像数据集 | #analysis | 图片网格、审核状态、标签与置信度筛选、请求模型分析 |
| 证据审核 | #review | 状态队列、缩略图、拖框、原始对照、人工修正、领取/释放、撤回与审核记录 |
| 三维配准 | #registration | Three.js 旋转缩放、二维控制点平面、残差、RMSE、点位聚焦、相机视锥体与原图 |
| 路网检索 | #plans | 审核快照、封闭/未知路段、单向箭头、步行/车辆路径及地图高亮 |
| 空间推理 | #reason | 多条件组合、后端多跳关系、关系依据、空间工件来源 |

页面可下载空白 JSON 模板，必须填入真实来源、对象、测量值及有效时间后提交；不再生成示例坐标。也可通过表单建立首个真实对象，未知坐标留空。图片采集时刻与“仅知道拍摄日期”必须主动填写其中一项，不默认使用上传时间；仅日期不补造午夜，按 UTC+14 至 UTC-12 的完整可能范围筛选，不计入时刻直方图。审核快捷键在输入框外生效：左右切图，1–3 切换接口支持的观察类别，Space 批准，Backspace 驳回；审核说明必填。

## 显示边界

- 地图点位、路段和关系来自录入数据，影像底图不证明数据真实性。缓冲圈及相机坐标转换适用于街区局部展示；正式距离、路网与空间推理以后端结果为准。
- 路径地图绑定回答引用的同一份有效审核路网。开放路段若引用了缺失、撤回或时间不符的证据，显示为未知；有效审核障碍物证据显示为封闭。普通浏览使用时间滑块，路径结果按接口的截止时间核对证据，不额外套用浏览窗口的起点。仅车辆道路单独标注。
- 地图叠加局部 40 米显示网格，用于视觉定位，不是测绘控制网，也不证明坐标精度。
- 时间窗按采集时间过滤，使用当前审核状态，**不是历史审核回放**。未来、窗外、撤回和待审记录不进入正式答案。更早证据只提示，不自动混入答案。
- 关系图只显示有效审核快照；引用了图片标注的关系还需满足当前证据时间窗。选中对象高亮同一谓词的最多四跳显式路径；blocks 不传递。该高亮用于浏览，查询证明以后端返回为准。
- 只有提供 camera_pose 的照片才绘制相机落点和 FOV；不从对象坐标猜测镜头位置。需填写 WGS84 坐标、朝向、水平视角、来源和实测性质；有椭球高时可绘制三维视锥体。扇区及视锥体的绘制长度不代表实际可视距离或遮挡分析。
- 三维展示输入对象范围、控制点、独立检查点及残差；不包含照片重建、点云匹配、实景网格或任意模型上传。WebGL 不可用时仍保留坐标表；地图退回 SVG 概览。
- 问答展示实际条件、运行编号和原图引用；句内脚标可联动证据卡片。AnySearch 单列「未核实背景」。路网可达不等于安全，路网算法不冒充旧版 OR-Tools 救援方案。

参考产品与实现对应见 [设计对照](../docs/frontend-design.md)。

## 维护与验证

api.js 管请求，state.js 管会话状态；workbench.js 提供地图/审核/数据集工作台，views.js 提供其余页面及证据组件；workspace.js / workspace.css 将这些组件组织为分组工作流和浮动窗口，维护拖动、边界和前后层级；gis.js 和 scene.js 管渲染生命周期，map.js 提供关系图与降级概览；app.js 绑定业务交互。intake.js 提供空白模板及来源标记检查；operations.css 管理数据来源窗与接入空状态。合成数据仅存在于 tests/fixtures，生产前端不包含演练模块。

atlas.css 在 workspace.css 后加载，管理导入设计的三套主题与布局适配；login.js / login.css 管理登录页，复用 app.js 的真实连接流程。登录主视觉 ⑤-1 使用用户提供的 default (2).jfif，原始 JPEG 内容直接保存为 assets/login-hero-01.jpg（1086 × 1448，3:4）；桌面等比裁切铺满右侧 50%，手机按 3:4 显示。⑤-2 至 ⑤-4 保留并禁用，待提供对应素材后启用。业务模块仍分文件维护，MapLibre / Three 保留本地固定版本，不加载参考 HTML 内的 CDN 脚本。

可选浏览器开发依赖不加入后端运行依赖：

    .venv/Scripts/python.exe -m pip install playwright==1.64.0
    # 先启动 8080 静态服务，8002 必须空闲；默认使用本机 Chrome。
    .venv/Scripts/python.exe tests/run_browser_check.py
    .venv/Scripts/python.exe tests/workspace_check.py
    .venv/Scripts/python.exe tests/vendor_browser_check.py
    .venv/Scripts/python.exe tests/map_consistency_check.py

脚本启动临时 team 后端并在完成后关闭；数据库在系统临时目录，固定测试令牌只用于该进程。模型和搜索使用测试桩，不调用实际供应商、不验证识别质量。浏览器仍可能请求地图瓦片。

覆盖登录失败/成功/刷新清除身份、八个工作台页面 × 320/768/1024/1440 宽度、地图与时间交互、拖框与审核意见保留、控制点、图片筛选、实际 FastAPI 认证链路下的上传/审核/问答/三类工件导入/推理、租约、409、权限、隔离与 HTML 转义。theme_check.py 另检查三套主题中的登录页布局、禁用入口、主视觉加载与画幅覆盖和可选 axe-core 对比度。截图输出到 Git 忽略的 data/frontend-check/。

workspace_check.py 单独验证整条标题栏拖动、方向键移动、边界限制、收起/恢复、放大/还原及审核草稿保留；不需要后端。account_browser_check.py 使用独立管理员与成员页面验证注册、审批、登录、改密、重置码找回和成员管理入口权限；默认连接 8080 前端和 8002 临时后端，run_browser_check.py 会在通用检查后执行它。

vendor_browser_check.py 要求真实 WebGL 画布出现且空现场没有对象标签，再用独立地图验证本地 worker 处理 GeoJSON 并渲染测试点位，同时检查不可信署名中的相邻事件属性和 javascript: 链接被清除。该检查不以 SVG 降级视图通过代替地图验证。

map_consistency_check.py 随 run_browser_check.py 执行，也可单独运行。它使用显式隔离的 UI 夹具，验证多份路网同名路段、路径快照、证据审核与撤回、未来及仅日期时间、过期快照、车辆标签和 SVG 降级显示，不写入正式数据库。浏览器脚本应串行执行。

real_data_browser_check.py 随 run_browser_check.py 执行，验证真实来源表单契约、未知位置保持空值、采集时间必填、空白模板、拒绝演练来源标记、数据窗以及断线后清除旧答案/标明旧快照。隔离数据库中的合成夹具只用于接口契约测试，不是实际测绘或模型识别质量的验证。

如已下载官方 axe-core 4.10.3，可额外执行：

    .venv/Scripts/python.exe tests/accessibility_check.py --axe /path/to/axe.min.js
    .venv/Scripts/python.exe tests/theme_check.py --axe /path/to/axe.min.js

检查 WCAG A/AA 自动规则、实体键盘选择、对话框焦点及 Escape。自动检查不能替代人工读屏验收。

theme_check.py 覆盖三套主题 × 八个路由，验证文字草稿、身份和主题按钮焦点保留，并检查 320/768/1024/1440 宽度下的顶栏控件；不传 --axe 时只检查交互、布局和浏览器异常。

### 真实数据工作台

「数据」浮窗显示服务地址、上次成功同步时间、地图来源、录入者、图片/已审观察数量和有效审核工件的可用性。显示的是手动刷新快照，不是实时推送；断线或同步失败会标明旧快照。模型调用失败不回退模拟结果。真实路网和三维配准仍需要有来源的人工采集、测绘或外部系统快照；系统不会根据底图编造道路通行状态或控制点。
