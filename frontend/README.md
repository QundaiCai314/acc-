# AI Disaster Commander · 空间指挥台

面向街区地震演练的高密度 GIS 工作台：空间对象树、影像地图、问答证据抽屉同屏联动。八个页面覆盖资料导入、图片分析、候选审核、三维配准、路网、复杂关系和现场回报。

使用原生 ES Modules 和 CSS，地图采用 MapLibre GL 5.6.2，局部三维采用 Three.js 0.180.0。固定版本脚本和许可证保存在 vendor/，来源及哈希见 vendor/sources.json；无需 Node 或构建步骤。影像瓦片来自 Esri World Imagery，需要联网，地图保留来源署名。部署方应按其服务条款安排生产用量及授权；可在 gis.js 替换瓦片源。第三方只接收瓦片范围请求，图片和令牌不发往瓦片服务。

## 预览

在仓库根目录运行：

    .venv/Scripts/python.exe -m http.server 8080 --bind 127.0.0.1 --directory frontend

打开 http://127.0.0.1:8080/#command 。ES Modules 必须通过 HTTP(S) 加载。

首次打开为**离线演练**：合成坐标、演练插画、合成相机位姿和观察记录，不代表影像底图所在地发生灾情。距离查询、时间筛选、审核/撤回、路网示例、三维点位可交互；修改只保存在当前页面内存中。不会自动导入后端。模型分析、自然语言、复杂联合推理、上传和公开搜索需要连接后端。

## 连接后端

在另一个 PowerShell 窗口启动当前版本后端：

    $env:DISASTER_CORS_ORIGINS = 'http://127.0.0.1:8080'
    .venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

点击「连接设置」。local 模式本机访问可留空令牌；team 模式填写个人令牌，参见 [多人部署](../docs/team-deployment.md)。已有进程需以对应 CORS 配置重启。schema 3 升级前应备份数据库。

- 令牌只在页面内存中保存，刷新页面后需重连；远程团队地址仅接受 HTTPS。
- 读取 /auth/me 和工作空间现场目录；照片以认证 Blob 加载，列表逐页读取。演练数据与服务端数据分开。
- 显示真实角色；写入权限、空间隔离、并发冲突由后端校验。使用「刷新」读取他人更新。
- 审核可领取五分钟租约，另一个审核员持有租约时后端拒绝提交；无租约时仍按首次成功提交生效。无自动续期，关闭页面后租约到期释放。409 保留当前审核意见供复核。
- AI 分析使用 Idempotency-Key，不自动重试。模型和搜索可能产生费用；超时后先核对结果再发起新分析。

## 页面及交互

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 现场态势 | #command | 实体树、影像底图、关系图、图层开关、距离圈、双端时间窗、播放、定向照片、问答与引用 |
| 资料导入 | #import | 地图 JSON、PNG/JPEG、可选相机位姿 |
| 图像数据集 | #analysis | 图片网格、审核状态、标签与置信度筛选、请求模型分析 |
| 证据审核 | #review | 状态队列、缩略图、拖框、原始对照、人工修正、领取/释放、撤回与审核记录 |
| 三维配准 | #registration | Three.js 旋转缩放、二维控制点平面、残差、RMSE、点位聚焦、相机视锥体与原图 |
| 路网检索 | #plans | 审核快照、封闭/未知路段、单向箭头、步行/车辆路径及地图高亮 |
| 空间推理 | #reason | 多条件组合、后端多跳关系、关系依据、空间工件来源 |
| 现场回报 | #field | 原图上传、外部观察录入，仍需审核 |

页面可下载配套的合成 JSON 模板；真实场地应替换坐标、对象、来源及有效时间。审核快捷键在输入框外生效：左右切图，1–3 切换接口支持的观察类别，Space 批准，Backspace 驳回；审核说明必填。

## 显示边界

- 地图点位、路段和关系来自录入数据，影像底图不证明数据真实性。缓冲圈及相机坐标转换适用于街区局部展示；正式距离、路网与空间推理以后端结果为准。
- 时间窗按采集时间过滤，使用当前审核状态，**不是历史审核回放**。未来、窗外、撤回和待审记录不进入正式答案。更早证据只提示，不自动混入答案。
- 关系图只显示有效审核快照；引用了图片标注的关系还需满足当前证据时间窗。选中对象高亮同一谓词的最多四跳显式路径；blocks 不传递。该高亮用于浏览，查询证明以后端返回为准。
- 只有提供 camera_pose 的照片才绘制相机落点和 FOV；不从对象坐标猜测镜头位置。需填写 WGS84 坐标、朝向、水平视角、来源和实测/演练性质；有椭球高时可绘制三维视锥体。扇区及视锥体的绘制长度不代表实际可视距离或遮挡分析。
- 三维展示输入对象范围、控制点、独立检查点及残差；不包含照片重建、点云匹配、实景网格或任意模型上传。WebGL 不可用时仍保留坐标表；地图退回 SVG 概览。
- 问答展示实际条件、运行编号和原图引用；句内脚标可联动证据卡片。AnySearch 单列「未核实背景」。路网可达不等于安全，路网算法不冒充旧版 OR-Tools 救援方案。

参考产品与实现对应见 [设计对照](../docs/frontend-design.md)。

## 维护与验证

api.js 管请求，state.js 管会话状态；workbench.js 提供地图/审核/数据集工作台，views.js 提供其余页面及证据组件；gis.js 和 scene.js 管渲染生命周期，map.js 提供关系图与降级概览；app.js 绑定交互。demo.js / demo-query.js 隔离合成数据。

可选浏览器开发依赖不加入后端运行依赖：

    .venv/Scripts/python.exe -m pip install playwright==1.64.0
    # 先启动 8080 静态服务，8002 必须空闲；默认使用本机 Chrome。
    .venv/Scripts/python.exe tests/run_browser_check.py

脚本启动临时 team 后端并在完成后关闭；数据库在系统临时目录，固定测试令牌只用于该进程。模型和搜索使用测试桩，不调用实际供应商、不验证识别质量。浏览器仍可能请求地图瓦片。

覆盖八页 × 320/768/1024/1440 宽度、地图与时间交互、拖框与审核意见保留、控制点、图片筛选、实际 FastAPI 认证链路下的上传/审核/问答/三类工件导入/推理、租约、409、权限、隔离与 HTML 转义。截图输出到 Git 忽略的 data/frontend-check/。

如已下载官方 axe-core 4.10.3，可额外执行：

    .venv/Scripts/python.exe tests/accessibility_check.py --axe /path/to/axe.min.js

检查 WCAG A/AA 自动规则、实体键盘选择、对话框焦点及 Escape。自动检查不能替代人工读屏验收。
