# AI Disaster Commander 原型

打开 `ai-disaster-commander-ui-prototype.html`，可交互体验事件接入、分析进度、现场态势、证据审核、方案比较和现场回报。

页面入口可通过地址参数直接打开：

- `?screen=import`：建立事件并选择本地 MP4 文件。原型只展示文件名，不上传文件。
- `?screen=analysis`：查看固定示例的模拟分析状态。
- `?screen=home`：现场态势总览，使用 `variant=A`、`B` 或 `C` 切换桌面总览、证据审核和移动任务流。
- `?screen=review`：逐条确认、驳回或纠正观察。
- `?screen=plans`：比较救援方案、查看约束和状态变化。
- `?screen=report`：提交一条本地模拟的现场回报。

移动设备预览可通过 `&device=mobile` 打开，也可使用页面右上方的预览切换。页面状态只保存在当前会话内；“确认东侧道路阻断”会令旧方案过期，之后可以模拟重算并人工确认新方案。所有视频内容、地图、风险和规划结论均为固定演示数据，不代表真实灾害分析或现场指挥建议。
